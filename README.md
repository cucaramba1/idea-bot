# Idea Bot

Telegram-бот, который принимает идеи Некита (текст, голос, форвард), разбирает их через `claude -p` и раскладывает в холст «Творческие идеи» его Obsidian-vault, синкая связи с холстами L2/L3. Отдельный бот-мозг работает поверх подписки Claude Code (без своего API-ключа), Python отвечает только за детерминированную запись файлов. Всё крутится одним asyncio-процессом под `launchd`.

## Установка

1. Заведи бота через [@BotFather](https://t.me/BotFather), получи токен.
2. Узнай свой Telegram id (например через [@userinfobot](https://t.me/userinfobot)): это `OWNER_ID`, бот отвечает только ему.
3. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN`, `OWNER_ID` (остальные поля обычно можно оставить по умолчанию).
4. Запусти автозапуск:

```bash
scripts/setup.sh install
```

## Команды `scripts/setup.sh`

| Команда | Что делает |
|---|---|
| `install` | ставит и запускает launchd-агент (создаёт `.env` из примера при первом запуске) |
| `restart` | перезапускает процесс |
| `stop` | останавливает |
| `status` | статус в launchd |
| `logs` | хвост `logs/ideabot.log` в реальном времени |
| `uninstall` | убирает автозапуск, `data/` (БД, медиа) не трогает |

## Темы холста

Темы, на которые раскладываются идеи внутри холста «Творческие идеи», заданы в `config/themes.yaml`:

```yaml
themes:
  - Бизнес-идеи / заработок
  - Контент
  - ...
fallback: Разное
```

Чтобы добавить тему, допиши её в список: новая группа появится на холсте при первой идее этой темы.

## `#холст`

Если в собственном тексте идеи есть `#название_холста` (например `#медиабаинг` или `#личный_бренд`), бот обязательно привяжет идею к этому холсту L2, даже если Claude решил бы иначе. Регистр и `_`/пробел не важны. Теги в форварде не считаются: это чужой текст, не мысль Некита. Тег, для которого холста не нашлось, попадает в карточку как предупреждение.

## Кнопки карточки

- **🔁 Поменять холсты**: выбрать другой набор холстов L2 вручную (без изменения текста заметки).
- **🔍 Копнуть глубже**: просит Claude поискать в вебе контекст по идее и дописывает раздел в заметку (доступно один раз).
- **↩️ Отменить**: полностью откатывает запись, удаляет заметку и все ноды/связи на холстах, которые бот создал.
- **➕ Дополнить / 🆕 Новая**: при похожей уже существующей идее, дописать в старую заметку или всё равно завести новую.
- **🔄 Разобрать ещё раз / Повторить**: для идей, которые не удалось разобрать (лимиты Claude) или расшифровать (голос).

## Известный риск

Если Некит правит холст руками в Obsidian ровно в момент, когда бот пишет на него же, возможна гонка: один из вариантов победит при следующей перезаписи файла. На практике это редкость (запись бота занимает доли секунды), но если холст выглядит странно сразу после правок руками и работы бота одновременно, проверь через `git diff`/резервную копию vault.

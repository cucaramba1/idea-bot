# Idea Bot

Telegram-бот: принимает идеи Некита (текст, голос, форвард), разбирает через `claude -p` и раскладывает в холст «Творческие идеи» в Obsidian. Подробности: `README.md`, текущее состояние: `HANDOFF.md`.

## Команды
- `scripts/setup.sh install | restart | stop | status | logs`. Темы холста: `config/themes.yaml`.
- Тесты: `uv run pytest -q`. На 14.10.2026 4 теста в `tests/test_pipeline.py` падают и без последних правок (старый долг, не регрессия).

## Правила
- Вызов Claude только через `ideabot/brain.py`. Модель по умолчанию `sonnet`, меняется переменной `CLAUDE_BATCH_MODEL`. Не переводить на Opus без причины, батчи едят дневной лимит.
- Бот отвечает только владельцу (`OWNER_ID`). Секреты в `.env` не читать и не коммитить, `data/` не трогать.
- Заметки в vault пишутся по стандарту `Правила оформления холстов.md` (атомарные, с `## Связанные заметки`).

# Idea Bot: дизайн

Дата: 2026-09-26. Статус: ждёт вычитки Некита.

## 1. Цель

Telegram-бот, куда Некит сбрасывает идеи голосом, текстом или форвардом. Бот не переписывает их дословно: Claude разбирает идею, даёт оценку, раскладывает её по теме внутри холста «Творческие идеи» и связывает с холстами второго уровня (L2) и заметками внутри них (L3), чтобы связь была видна и в canvas, и в Graph View.

Критерии успеха:
- любая идея, отправленная боту, оказывается в vault, даже если сломался Claude или whisper;
- идея лежит одной заметкой в `Творческие идеи/`, в своей теме на холсте, со строкой в MOC;
- в каждом связанном L2-холсте есть file-нода идеи, а в заметке идеи есть wikilink на L3 (или на L2, если L3 не нашлась);
- от отправки до карточки в Telegram обычно не больше минуты.

## 2. Термины

- **L2**: холсты верхнего уровня в корне vault (`Медиабаинг.canvas`, `Личный бренд.canvas`, `Кулинария.canvas` и т.д.). Сам `Творческие идеи.canvas` в роли L2-цели не выступает.
  Сюда же попадают городские холсты в корне (`Нячанг.canvas`, `Дананг.canvas`).
  MOC L2 ищется так: сначала `<L2>/<L2> — карта заметок.md`, потом `<L2> — карта заметок.md` в корне (у «Фитнеса» есть оба, берётся из папки).
- **L3**: file-ноды (`.md` заметки) внутри L2-холста.
- **Тема**: группа на холсте «Творческие идеи», куда кладётся идея.
- **Тип**: характер идеи, от него зависят тон и поля разбора.

## 3. Решения, принятые в брейншторме

| # | Решение |
|---|---|
| Бот | Отдельный бот (свой токен BotFather), отдельный проект `~/Claude Code/idea-bot` |
| Модель | `claude -p` на подписке, без API-ключа |
| Хостинг | Мак, launchd, как Dungeon Tasks |
| Целевой холст | Существующий `Творческие идеи.canvas`, новый холст не создаётся, имя не меняется |
| Превью | Нет. Бот пишет сразу, потом присылает карточку с кнопками |
| Связи | Идея живёт только в `Творческие идеи/`. В L2 только file-нода-ссылка и стрелка к L3 |
| Несколько L2 | Можно |
| Досуг, Фитнес | Детально по L3 не разбираются, только до уровня групп |
| Копнуть глубже | Только по кнопке, с веб-поиском |
| Статусы, `/ideas`, `/top` | Не на старте |
| Старые холсты | Миграция L2 в новый формат это отдельная сессия, не часть бота |

## 4. Типы и темы

### Типы (поле `type`)

| Тип | Тон | Поля разбора |
|---|---|---|
| 💼 бизнес | честный, без смягчений | суть, потенциал 1–10, затраты/сложность, деньги (как и сколько), риски и слабые места, совпадение с целями, первый шаг |
| 🎬 контент | поддерживающий | суть, формат, площадка, хук, как усилить, первый шаг |
| 🧠 мысль | поддерживающий | суть, развитие мысли, с чем это связано из уже имеющегося |
| 🎲 прочее | лёгкий | суть, короткий комментарий, без оценок |

Цели для поля «совпадение с целями» берутся из `Продуктивность и привычки/Мои цели.md`. Если файла нет, поле пропускается.

### Темы (группы на холсте)

Список в `config/themes.yaml`, порядок = порядок групп в ряду:

```yaml
themes:
  - Бизнес-идеи / заработок
  - Контент
  - Мысли и заметки
  - Геймдизайн
  - Музыка
  - Разное
fallback: Разное
```

- Бот ищет на холсте группу с точно таким `label`. Если её нет, создаёт.
- Существующие группы «Геймдизайн» и «Бизнес-идеи / заработок» переиспользуются как темы. Группы-подборки («Музыка — находки и инструменты (2025 I)», «Идеи и находки (2026 II)», «Разное — цитаты, студия, перформанс (24.09.2026)») не трогаются, для тем «Музыка» и «Разное» создаются новые группы.
- Claude выбирает тему только из списка. Не подошло ничего, значит `fallback`.

## 5. Структура в vault

### Заметка идеи

Путь: `Творческие идеи/<Заголовок>.md`. Имя файла чистится по правилу vault: `:` → ` —`, `/` → `-`. Если файл с таким именем уже есть, добавляется ` (2)`, ` (3)` и т.д.

```markdown
---
type: контент
theme: Контент
created: 2026-09-26
source: голос
forward_from: "Канал X"   # только для форвардов
idea_bot_id: 42
---
# Заголовок

<разбор по полям типа>

> [!quote]- Исходник
> <текст / транскрипт / текст форварда; для видео: "(видео не смотрел, только подпись)">

## Связанные заметки
- [[Название L3-заметки]]
- [[Медиабаинг — карта заметок]]
```

Для форварда в разборе явно сказано, что это чужой пост, а не мысль Некита. Мысль Некита здесь только его комментарий, если он был.

### MOC

В `Творческие идеи/Творческие идеи — карта заметок.md` под заголовком `## <Тема>` добавляется `- [[Заголовок]]`. Нет заголовка, значит бот добавляет его в конец файла.

### Холст «Творческие идеи»

- Тематические группы стоят отдельным рядом **ниже** всех существующих нод (y = max(y+height) + 120), слева направо, ширина группы 460, шаг 500.
- Идея = file-нода 400×120 внутри группы, новые добавляются вниз. Группа растёт по высоте.
- Существующие ноды не двигаются.

### Синк в L2

- В L2-холсте одна группа `💡 Идеи` справа от всего содержимого (x = max(x+width) + 200). Если группа уже есть, бот её переиспользует.
- Внутри группы file-нода на заметку идеи.
- Если выбрана L3 и она есть в этом холсте как file-нода, добавляется edge «нода идеи → нода L3».
- Для Досуга и Фитнеса L3 это группа: edge идёт к group-ноде.
- Wikilink в заметке идеи: на L3, если она есть. Иначе на MOC L2 (`<Тема> — карта заметок`), если он есть. Иначе на `[[<L2>.canvas]]`. Будет ли ссылка на `.canvas` видна в Graph View, пока не проверено; проверить на этапе реализации и отметить результат в README.
- L3-заметки бот не редактирует.

### Запись файлов

- Напрямую в файловую систему, без Local REST API: работает при закрытом Obsidian.
- Атомарно: запись во временный файл рядом, затем `os.replace`.
- Canvas: читается JSON, меняется, пишется обратно с `indent=1` и `ensure_ascii=False`, как в текущих файлах. Неизвестные поля нод сохраняются.
- Известный риск: если в момент записи этот холст открыт и редактируется в Obsidian, одна из сторон может перетереть изменения другой. Не лечится, только документируется.

## 6. Поток в боте

### Вход

- Доступ только для `OWNER_ID`, остальное игнорируется.
- **Текст**: как есть.
- **Голос / кружок / аудио**: скачать → `mlx_whisper` (логика из `dungeon-tasks/dungeon/stt.py`, свой `initial_prompt` под идеи) → текст.
- **Форвард**: текст или подпись + источник (`forward_origin`: канал, пользователь или скрытый). Фото скачиваются в `data/media/<id>/` и передаются Claude путями, Claude читает их тулом `Read`. Видео не скачиваются, в заметке помечается «видео не смотрел».
- **Альбом** (`media_group_id`): все части склеиваются в одну идею.
- **Склейка**: все сообщения от Некита, пришедшие в течение 5 секунд после последнего, собираются в одну идею. Его собственный текст считается комментарием, форварды источниками.

### Явный холст

- Хэштег `#медиабаинг`, `#личный_бренд` и т.п. сверяется кодом с названиями L2: регистр не важен, `_` = пробел. Совпавшие L2 обязательно попадают в связи.
- Фраза вида «для медиабаинга» разбирается Claude, код её не ловит.
- Хэштег, не совпавший ни с одним L2, игнорируется, в карточке пишется «холст #xxx не нашёл».

### Обработка

1. Бот отвечает `⏳ Разбираю…`.
2. Идея встаёт в очередь. Обрабатывается по одной (asyncio worker + lock, как в Dungeon).
3. Бот собирает индекс vault (раздел 7) и вызывает Claude (раздел 8).
4. Если Claude вернул `duplicate_of`: бот спрашивает `[➕ Дополнить «X»] [🆕 Новая]` и ждёт ответа. Дополнение = раздел `## Дополнение (дата)` в конец старой заметки перед `## Связанные заметки`, новые связи добавляются к старым.
5. Запись: заметка → MOC → холст «Творческие идеи» → каждый L2.
6. Сообщение `⏳` редактируется в карточку:

```
💡 Заголовок
🎬 контент · тема «Контент»        (для бизнеса ещё: оценка 7/10)
🔗 Медиабаинг → «Офферы», СММ
[🔁 Поменять холсты] [🔍 Копнуть глубже] [↩️ Отменить]
```

### Кнопки

- **🔁 Поменять холсты**: клавиатура со всеми L2 с галочками на текущих, плюс `✅ Готово`. После «Готово» бот убирает ноды и edge из старых L2 и wikilinks на них, короткий вызов Claude подбирает L3 в новых L2, бот пишет новые связи и обновляет карточку.
- **🔍 Копнуть глубже**: `claude -p` с тулами `WebSearch,WebFetch`, таймаут 5 мин. Дописывает `## Копнули глубже (дата)` со списком источников-ссылок перед `## Связанные заметки`. Карточка получает отметку «🔍 дополнено».
- **↩️ Отменить**: удаляет заметку, строку MOC, ноду на холсте «Творческие идеи», ноды и edge во всех L2. Пустую группу `💡 Идеи` в L2 тоже удаляет. Если это было «Дополнение», убирает только добавленный раздел и новые связи.

## 7. Индекс vault для Claude

Строится при каждом вызове, из файлов, без кэша (vault меняется руками):

- список L2: имя холста + есть ли MOC;
- для каждого L2 группы (`label`) и file-ноды (имя заметки без пути);
- для `Досуг` и `Фитнес и здоровье` только группы (список в `config/settings.yaml`, ключ `shallow_canvases`);
- список тем;
- заголовки заметок в `Творческие идеи/` (для поиска дублей);
- текст `Мои цели.md`, если есть.

Ожидаемый размер: несколько тысяч токенов. Если выйдет больше 15k, резать сначала самые большие L2 до уровня групп.

## 8. Контракт с Claude

Вызов (как в `dungeon-tasks/dungeon/coach.py`):

```
claude -p --output-format json --no-session-persistence \
  --system-prompt <SYSTEM> --json-schema <SCHEMA> \
  --tools "Read" --allowedTools "Read" --add-dir data/media/<id>   # только если есть фото
  --tools ""                                                        # без фото
```

Для «Копнуть глубже»: `--tools "WebSearch,WebFetch" --allowedTools "WebSearch,WebFetch"`. Без `--allowedTools` в неинтерактивном режиме тул упрётся в запрос разрешения.

Таймаут 3 мин. Вход в stdin: текст идеи, источник, пути к фото, явные L2, индекс vault.

JSON-ответ:

```json
{
  "type": "бизнес|контент|мысль|прочее",
  "theme": "<одна из тем>",
  "title": "<до 80 символов>",
  "body_md": "<разбор по полям типа, markdown>",
  "score": 7,                       // только для бизнеса, иначе null
  "links": [
    {"l2": "Медиабаинг", "l3": "Офферы", "l3_kind": "file|group|none"}
  ],
  "duplicate_of": null              // или заголовок существующей идеи
}
```

Проверка кодом: `theme` из списка (иначе fallback), `l2` существует (иначе выкинуть), `l3` существует в этом L2 (иначе `none`), явные L2 из хэштегов добавлены, если Claude их не вернул.

## 9. Хранилище бота

SQLite `data/ideas.db`:

- `ideas`: id, created_at, status (`pending|saved|raw|undone`), source, raw_text, note_path, type, theme, tg_chat_id, tg_card_msg_id, is_append_to (id или null);
- `links`: idea_id, canvas_path, node_id, edge_id (nullable), wikilink;
- `media`: idea_id, path, kind.

Нужна для Поменять/Отменить/Дополнить и для повторов после сбоев.

## 10. Ошибки

Главное правило: идея не теряется.

| Сбой | Что делает бот |
|---|---|
| Claude упал, таймаут, лимиты, битый JSON | Сырая заметка в тему «Разное» с тегом `#неразобрано`, исходник внутри. Карточка с `[🔄 Разобрать ещё раз]`: повторный разбор переписывает заметку и переносит в правильную тему |
| whisper упал | Сообщение об ошибке, файл остаётся в `data/media/`, кнопка `[🔄 Повторить]` |
| Запись в vault не удалась | Идея остаётся `pending` в SQLite, повтор каждые 5 мин, сообщение Некиту |
| Бот перезапустился посреди обработки | На старте все `pending` снова ставятся в очередь |
| Мак спал | Telegram хранит апдейты до 24 ч, бот разбирает их после пробуждения |

## 11. Структура проекта

```
idea-bot/
  pyproject.toml          # uv, aiogram, pyyaml, python-dotenv; dev: pytest
  .env                    # BOT_TOKEN, OWNER_ID, VAULT_DIR, CLAUDE_BIN, WHISPER_BIN
  config/themes.yaml
  config/settings.yaml    # shallow_canvases, окно склейки, таймауты
  ideabot/
    config.py
    bot.py                # хендлеры aiogram, кнопки
    collector.py          # склейка сообщений и альбомов
    stt.py                # whisper
    brain.py              # индекс vault + вызов claude + валидация
    vault/notes.py        # заметка, MOC
    vault/canvas.py       # чтение/запись canvas, группы, ноды, edges
    vault/sync.py         # сборка: запись/перевешивание/отмена идеи
    db.py
    worker.py             # очередь, повторы
  scripts/setup.sh        # install/start/stop/restart/logs, launchd com.cucaramba.idea-bot
  tests/
```

## 12. Тестирование

- pytest на временной копии мини-vault (фикстура), живой vault тесты не трогают.
- Покрыть: имя файла и коллизии, MOC (есть заголовок / нет), размещение групп и нод на холсте, синк в L2 (с L3 file / group / none), отмена (включая удаление пустой группы), перевешивание холстов, дополнение дубля, хэштеги, склейка сообщений, валидация ответа Claude, сырая заметка при сбое.
- Claude и whisper в тестах подменяются заглушками.
- Живой прогон в конце: текст, голос, форвард с фото, форвард с комментарием, хэштег, дубль, поменять холсты, копнуть глубже, отменить. Перед живым прогоном бэкап `Творческие идеи.canvas`, MOC и затронутых L2.

## 13. Вне скоупа

- Миграция старых L2 (`Личный бренд`, `Обо мне`, `Медиабаинг` и др.) в новый формат: отдельная сессия.
- Статусы идей, `/ideas`, `/top`.
- Разбор видео по кадрам.
- Страховка через Telethon на время сна мака.

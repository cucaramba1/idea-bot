# Idea Bot на сервер (пакеты записи), план от 08.11.2026

Статус: ждёт одобрения Некита.

## Цель
Бот принимает идеи и разбирает их на сервере Contabo 24/7. Запись в vault делает ноут через пакеты и applier (как у reels-radar), ноут можно выключать, идеи копятся в очереди.

## Что уже есть
- Мозг (`claude -p`) и голос (Groq) уже удалённые, `CLAUDE_BIN` ведёт на сервер по SSH.
- Приём пакетов, applier, rsync-канал и зеркало vault (`~/vault-mirror/main`) работают у reels-radar, код `reels_radar/packets.py` служит образцом.

## Что придётся менять
Всё, что трогает vault, сейчас вызывается из `pipeline.py` синхронно через `Writer`:
`save_raw`, `save_new`, `append`, `undo`, `relink`, `add_deep`, плюс `add_theme` (правит `config/themes.yaml`) и `build_index` (читает vault).

1. Серверный `RemoteWriter` с тем же интерфейсом: каждая операция кладёт пакет в `data/outbox`, идея получает статус `queued`, продолжение (`saved`, обновление карточки) идёт по ack.
2. Домашний applier: берёт пакет, вызывает настоящий `Writer` теми же функциями. Журнал отката, который сейчас лежит в `ideas.db`, дома заводится отдельным файлом `applier.db` (ключ idea_id), чтобы `undo` находил свои записи.
3. Идемпотентность: журнал `data/applied` по ключу пакета, повторная доставка ничего не пишет второй раз.
4. `build_index` на сервере читает зеркало vault (задержка до 5 минут принимается). Проверить, что `Творческие идеи.canvas` и папки идей есть в зеркале.
5. `add_theme`: тоже пакет (темы живут в `config/themes.yaml` дома, зеркалируем обратно).
6. Данные: копия `ideas.db` на сервер (Python backup API), `data/media` не переносим пока (нужно только для незавершённых идей, проверить).
7. Сервер: код, `.venv`, `.env` (токен, Groq, `CLAUDE_BIN` локальный серверный, `OWNER_ID`), systemd `idea-bot.service` (MemoryMax 300M). Дома: убрать из `boot-stagger`/`resource-guard`, оставить disabled.
8. Тесты: по образцу `tests/test_packets.py` (round trip, повторная доставка, сбой записи возвращает статус, undo). 4 уже падающих теста `test_pipeline.py` не чиню в рамках переноса (старый долг), но проверю, что их число не выросло.

## Цена и риски
- Объём: заметная работа, примерно как перенос записи у радара (новый модуль + правки pipeline и bot + тесты).
- Карточка идеи будет не мгновенной: после записи до 5 минут ожидания ack (сейчас запись мгновенная).
- Операции зависят друг от друга (analyze -> save -> relink -> deep): каждая ждёт ack предыдущей.
- Один токен = один getUpdates: домашний бот в момент переключения должен быть остановлен.

## Критерии готовности
- Идея текстом и голосом доходит до заметки в холсте через пакет, карточка обновляется по ack.
- Отмена, «Поменять холсты» и «Копнуть глубже» работают через пакеты.
- Повторная доставка не создаёт вторую заметку.
- Ноут выключен: бот принимает идею и показывает статус очереди, после включения запись догоняется.

## Откат
Остановить сервисный бот, вернуть `ideas.db` с сервера, включить домашний `launchctl enable` + `bootstrap` + `disable`.
